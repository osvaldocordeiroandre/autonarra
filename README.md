# AutoNarra

Seu áudio narrado e o roteiro viram um **vídeo vertical pronto** para TikTok e YouTube Shorts: legenda sincronizada com a sua voz, uma imagem por cena, zoom, gancho, trilha, efeitos e os textos para postar.

## Baixar
Pegue o `AutoNarra-Setup-x.y.z.exe` mais recente em **[Releases](https://github.com/osvaldocordeiroandre/autonarra/releases/latest)**.

Depois de instalado, o app se atualiza sozinho: ele procura versões novas aqui, baixa em segundo plano e mostra **"Reiniciar e atualizar"** na barra de título.

## Requisitos
- Windows 10 ou 11 (64 bits)
- FFmpeg (versão full): `winget install Gyan.FFmpeg`

> O instalador ainda não tem assinatura digital, então o Windows pode mostrar o aviso do SmartScreen. Clique em **Mais informações → Executar assim mesmo**.

Este repositório guarda só os instaladores.
